# Burevestnik_BinToCsvConverter

В рамках прохождения производственной практики необходимо было разработать программные модули для удобной работы с бинарными файлами, содержащими CAN-сообщения от различных устройств.

**Программа «BinToCsvConverter», предназначенная для конвертации бинарных файлов в CSV-формат.**

Входные данные представляли собой бинарные файлы с фиксированной структурой сообщений.

Реализованы побайтовое считывание файла с накоплением буфера и поиском маркерного заголовка сообщения, парсинг сообщений с помощью побайтовых сдвигов (извлечение времени сообщения, идентификатора, содержания сообщения), сохранение в CSV-файл. Для удобства пользователя было добавлено сохранение последней используемой папки в реестр, автоматическое создание имени выходного файла. Также был создан интерфейс с сообщениями пользователю, кнопками и прогресс баром. 

Разработка BinToCsvConverter проходила Qt Creator 5.6. Программа была протестирована на реальных файлах с заводскими данными.
